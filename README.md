# EduFlow – AI-Powered Learning Management System

EduFlow is a smart Learning Management System (LMS) designed to improve the educational experience through automation, artificial intelligence, and data-driven insights.

The platform connects students, teachers, parents, and administrators through an integrated educational environment.

## Project Overview

EduFlow aims to simplify academic management, enhance student performance monitoring, and automate educational operations.

## User Roles

- **Student:** Access courses, attend sessions, take exams, watch lessons, and track academic progress.
- **Teacher:** Manage courses, groups, sessions, exams, and student performance.
- **Parent:** Monitor students' attendance, academic progress, and payments.
- **Admin:** Manage the platform, users, courses, payments, and overall operations.

## Core Features

- Course and Group Management
- Online Exams and Assessments
- Student Performance Tracking
- Attendance and Absence Monitoring
- Video Access Control
- Assignments and Submissions
- Payment and Billing Management
- Teacher Earnings Tracking
- Notifications and Complaints Management
- Role-Based Dashboards

## AI & Automation

- AI-Powered Educational Chatbot
- Retrieval-Augmented Generation (RAG)
- Intelligent Academic Reports
- Automated Notifications and Reminders
- AI-Assisted Learning and Assessment

## Technology Stack

| Technology | Purpose |
|---|---|
| Supabase | Backend Infrastructure |

| n8n | Workflow Automation |
| AI / LLMs | Intelligent Educational Features |
| Vector Search | RAG and Semantic Retrieval |

## Project Architecture

EduFlow follows a modular architecture combining database management, backend services, frontend interfaces, and workflow automation.
